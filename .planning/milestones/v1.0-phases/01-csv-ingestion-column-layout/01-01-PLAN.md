# Plan 01-01: CSV reader + header scanner

## Objective

Add a stdlib-only Python CLI under `quizify-csv-to-json-webhook/` that reads Quizify CSV exports with `encoding="utf-8-sig"` and `newline=""`, classifies the header row into **6 fixed contact columns**, **K dynamic question columns**, and **6 trailing analytic columns** (defaults overridable via `--trailer-columns`), and prints a **stderr-only** `--dry-run` summary (counts + ordered dynamic headers) with **no cell values**. Implements **D-01–D-12** from `01-CONTEXT.md`. **CONV-01** JSON array output is **Phase 2**; Phase 1 satisfies CONV-01 by establishing a **pipable** CLI (`stderr` diagnostics only; **stdout** unused when only `--dry-run` / no conversion).

## must_haves

- Running `python quizify-csv-to-json-webhook/quizify_csv_ingest.py --dry-run quizify-csv-to-json-webhook/docs/quizify-submissions.csv` exits **0** and prints to **stderr** lines containing **`Questions (dynamic): 20`**, per-header **`Dynamic:`** lines including **`Rango de edad`**, and **does not** print cell payloads from data rows (no `@` characters from email cells — stderr may contain `@` only if absent from dynamic headers; sample dynamic headers have no `@` so assert **`@` not in stderr** for this fixture).
- Classification matches **RESEARCH.md** verified split: **6 / 20 / 6** columns on the sample header.
- `pytest quizify-csv-to-json-webhook/tests/test_layout.py -q` exits **0**.

<threat_model>
**ASVS L1 — local CLI, PII-bearing CSV**

| Threat | Mitigation in this plan |
|--------|-------------------------|
| PII leaked via logs / dry-run | Dry-run and INFO logs list **headers and counts only** — never iterate printing `row` cell values to stderr in `--dry-run` or default paths (D-02). |
| Path tricks | Single positional file path opened **read-only** via `pathlib.Path`; no `eval` of CSV contents. |
| Injection via `--trailer-columns` | Split on comma only; validate non-empty segments after strip; reject empty trailer list with exit code 2 and stderr message containing **`trailer-columns`**. |

**Block on:** none requiring network; file read is explicit path only.
</threat_model>
