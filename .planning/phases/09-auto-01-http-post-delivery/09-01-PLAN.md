`_HttpPostSink` (Plan 09-02 will implement; this plan only writes tests against the contract):
```python
class _HttpPostSink:
    def __init__(self, url: str, headers: list[tuple[str, str]] | None, timeout: float): ...
    def __enter__(self) -> "_HttpPostSink": ...
    def write(self, row: dict) -> None: ...   # appends to self._rows
    def __exit__(self, exc_type, exc, tb) -> bool: ...  # POSTs iff exc_type is None and rows non-empty
    def close(self) -> None: ...              # no-op
```

`_NoRedirectHandler` — `urllib.request.HTTPRedirectHandler` subclass; `redirect_request` raises `urllib.error.HTTPError(req.full_url, code, "http_unexpected_redirect", headers, fp)`.

`_log_http_failure(reason: str, *, status: int|None=None, reason_class: str|None=None, body_bytes: int|None=None) -> None` — emits via `logging.error("http_failure reason=%s status=%s reason_class=%s body_bytes=%s", ...)` with `-` for unknowns.

`_parse_header(s: str) -> tuple[str, str]` — argparse `type=` callable; rejects via `argparse.ArgumentTypeError` with one of: `header_crlf_rejected`, `header_missing_colon`, `header_empty_name`, `header_invalid_name`.

`_https_url(s: str) -> str` — argparse `type=` callable; rejects via `argparse.ArgumentTypeError("post_url_https_required")` if `urlsplit(s).scheme != "https"` or empty netloc.
